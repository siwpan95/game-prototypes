# mcclone3d —— 《我的世界》风格 3D 体素沙盒（基于 3dworld 引擎）

`mcclone3d` 是 [`mc-clone`](https://gitee.com/siwpan/mc-clone)（MC1 文字冒险 + MC2 2D 侧视）
的 **3D 重做版**：把方块世界的玩法搬到真三维体素场景里，引擎用
[`siwpan/3dworld`](https://gitee.com/siwpan/3dworld) 的 `world3d`。

> **三仓关系**：`3dworld` 是**引擎与渲染能力本体**；`mcclone3d` 是**消费方**
> （玩法 + 贴图规则）；`mc-clone` 是**旧版**（2D / 文字形态），**原样保留、不再改动**。

## 引擎从哪来（**必读**）

本项目**不自带引擎副本**，运行时从 `3dworld` 检出导入：

```bat
:: 方式一（推荐）：把 3dworld 检出加进 PYTHONPATH
set PYTHONPATH=G:\repos\3dworld          :: 本机示例；换机请换成你的检出目录
python examples\mcclone3d.py

:: 方式二：设 MC3D_ENGINE_ROOT
set MC3D_ENGINE_ROOT=G:\repos\3dworld

:: 方式三：装成可编辑包（一次性）
python -m pip install -e G:\repos\3dworld
```

找不到引擎时 `mcclone3d/_engine.py` 会抛一条**点名说清三条通路**的错误，不会静默降级。

## 运行

```bat
python examples\mcclone3d.py                 :: 交互：漫步 / 挖 / 放 / 昼夜流动 / 生物
python examples\mcclone3d.py --phase 0.75    :: 直接跳到午夜（0=日出 0.25=正午 0.5=日落）
python examples\mcclone3d.py --smoke 3       :: 3 秒后自动退出（冒烟）
python examples\mcclone3d.py --flag auto,verbose   :: 自动机 + 每秒心跳（含光照读数）
python examples\shot_vista.py                :: 截图到 shots/（地貌 / 材质 / 选中框）
python examples\shot_hud.py --hurt           :: 截图（HUD：半血半饱，读数可对拍）
python examples\shot_day.py                  :: 同一机位拍三张（正午 / 日落 / 午夜）
python examples\shot_mobs.py                :: 同一机位拍两张（白天羊猪 / 午夜僵尸）
python examples\shot_cave.py                :: 洞口井 + 洞内矿石与火把照明
python examples\shot_weather.py             :: 雨天 / 雪天（同一机位，只差天气）
python examples\shot_village.py             :: 村庄：白天俯视整村 / 夜里灯火
python -m mcclone3d.cli                      :: headless 验收 17 条（不需要窗口）
python -m tests.run_all                      :: 全部单测（零 GL）
```

**操作**：`WASD` 移动 ｜ `Space` 跳 ｜ 鼠标左键拖动转向 ｜ **按住左键挖 / 右键放** ｜
`1`–`9` 选 hotbar ｜ `F` 切飞行 ｜ `R` 重生 ｜ `Ctrl+S` 存档 ｜ `Esc` 退出。

**生存要点**：石类**必须带镐**才挖得动（徒手挖了白挖，且慢 5 倍）；工具会磨损断裂；
挖到的东西掉在地上，**走近才捡得起来**；饿了会掉血，吃面包（`9` 格后可合成）回血。

**光照要点**：天黑不是"调暗一个滤镜" —— 天光按列灌下来、水每格挡 1 级、
洞里是黑的，所以**挖个竖井能把光引下来**（`cli --only daylight` 就是这么验的）。

**生物要点**：羊猪白天到处走、**打了会逃**；僵尸只在**夜里或暗处**刷，
看见了会追上来打（有攻击冷却，贴太近会被它保持间距）；**白天在露天会自燃烧死**
（烧死不掉东西），**挖个洞躲着就没事**（洞里天光为 0）。左键瞄准生物即可挥击，
隔墙打不到。`cli --only mobs` 一条命令覆盖全部判据（含 300 只性能口径）。

**水与天气要点**：**挖穿海层下的岩层，海水会灌进洞**（垂直灌注，一次到位、不震荡）；
**内陆的洞永远是干的**；水**不会横向摊成水面**（已知边界，见设计稿 §十三）。
天气每 90 秒换一段（晴/雨/雪），**雨天整体变暗（天光 ×0.72）、雪天稍亮（×0.80）**，
雨雪是屏幕粒子，不影响玩法判定。`cli --only water,weather` 覆盖全部判据。

**村庄要点**：地图上平坦的地方会有一座**村庄** —— 四栋房子（有门、能走进去，
屋里有火把）、十字砂砾路、中间一口井、南北两块**麦田**（打掉麦子掉小麦，
3 麦能烤 1 个面包）。村里有**村民**在走动（只在村里刷，村外没有）。
⚠ **村庄夜里是安全的**：村里的火把把中心的光照顶到 **12**，而僵尸只在 **≤7** 的地方刷
⇒ 僵尸刷不进村。`cli --only village` 一条命令覆盖全部判据。

**洞穴要点**：地表能看到**自然洞口**（worm 隧道打穿了表土），走下去就是洞穴；
洞里**很黑**（天光进不去，只靠火把），**洞顶有 3 格岩层**所以不会一挖塌到天，
**洞里不会有水**（水下地形整列不挖——本项目还没有流体系统）。
矿脉按深度分层：**煤 y<40 / 铁 y<28 / 金 y<16 / 钻石 y<8**（随世界高度缩放），
越深越稀有，簇也越小。`cli --only caves` 一条命令覆盖全部判据。

## 与引擎的接法（不改 3dworld 一行）

只用引擎的三个**公开扩展点**（见 [`docs/阶段计划.md` §二](docs/阶段计划.md)）：

| 扩展点 | 用途 |
| --- | --- |
| `world3d.host.registry.SERVICES`（可写封闭表） | 登记服务短名 `mcclone` → `mcclone3d.kernel:McCloneKernel` |
| `WORLD3D_CONFIGS` 环境变量 | 让引擎来**本项目**的 `configs/` 读配置树 |
| `world3d.host.tree.mount_tree(path, want=...)` | 挂载配置树（demo 与 headless 验收**共用同一份接线**） |

## 贴图：走引擎的 UV 投影与贴图规则

* 像素材质**程序化生成**（16×16，逐字节确定性）⇒ 仓里没有二进制素材、无授权问题；
* 每个面的 UV 由 `u = (p · u_dir) * scale + offset` 算出（与 Source `texinfo` 同构），
  密度 `1/(图集列数 × tile_size)` ⇒ **一格方块面恰好跨一格图集格**，且跨方块连续；
* 图集映射、平铺回绕（`TexWrap.REPEAT`）、密度体检（`texproj.density_report`）都用引擎那一套。

三个实测踩过的坑（面的手性 / 图集 v 轴翻转 / 绕序）都写在
[`mcclone3d/mesh.py`](mcclone3d/mesh.py) 的模块说明里，并各有单测钉住。

```
python -m tests.run_all     # 零 GL 单测：方块表/贴图/世界/网格/物理/拾取/内核
```

判据是**可量化的比较**，不是"看起来对"：同种子逐格相同、面数与逐格统计相符、
跳高与解析解对拍、挖掘耗时与公式对拍、配方反向自检、自动机三种帧率结果一致、
存档往返逐字段相等、**水列的层次（15/14/0）与竖井天光衰减**、HUD 读数与内核状态一致、
**生物侧**：上 1 格台阶的过程峰值、追击最近距离 = 攻击间距 0.75、攻击冷却 ≥1s、
白天只刷被动/夜里能刷敌对、300 只每帧 < 6ms；
**洞穴侧**：挖空比例落在 3~25%、越深越密、基岩完好、地表无矿、矿脉不越界、
矿量随深度递减、洞口通且可达、洞内天光为 0、生成耗时 < 8s；
**村庄侧**：地基无空洞、四栋房门洞通/屋顶不透/屋内有火把、农田作物长在土上、
**结构与树都不进存档**、同种子逐格相同、老档读回村庄在原位、
**村中心无暗格（僵尸刷不出来）**、村民只在村里刷且有人口上限。

## 已知边界

* 世界是**有限箱体**（默认 256×256×64 ≈ 220 万方块）；无限地形要区块流式加载，属 Phase 2。
* **生物不进存档**（v3）：读档后自然重刷；要"家畜圈养"需升 v4，见设计稿 §七。
* **村庄也不进存档**（走 `set_generated`）：老档不用升级，但**改了村庄摆放规则，
  老档里的村庄会跟着移位**（与树/洞穴/矿脉同一性质，见设计稿 §十四）。
* **村民不交易**、房屋里没有门/床/箱子（要新的方块类型与交互，属 Phase 3）；
  结构只有村庄一种，且每村布局共用同一套模板（只按哈希变材质）。
* 生物**不会游泳**（水不算固体，直接落过水）；不会绕迷宫（贪心 + 跳台阶，设计稿 §二）。
* **洞里初始不会有水**（生成时水下地形整列不挖）；**玩家挖穿海层**水才会灌进去。
* 水**不会横向铺开成水面**（只有垂直灌注，见设计稿 §九/§十三）；
  洞顶**不会塌方**（没有方块掉落物理，Phase 3）。
* 不含任何 Minecraft 官方素材；本项目是**机制致敬**，与原作无隶属关系、不声称任何商标。
* 引擎侧已知差异（`MeshData.triangle_count` 对索引网格按 `//9` 少算 3 倍）只在本仓
  **记录 + 断言 + 回避**，不就地改 3dworld。
