# Idle Clicker — Canvas 放置挂机

一个用 Python tkinter 构建的放置/点击类游戏。融合了**纪元进阶、科技树、英雄系统、装备掉落（部位/词条/套装）、英雄主动技能、黄金按钮、限时活动、日常任务、转生挑战**等系统，35 种装备从石器时代一路发展到太空时代。灵感来源于《兽人领地》《极简塔防》和《巴尔的遗产》。

- **P0（已完成）**：离线收益、自动保存、30 成就、每日奖励、里程碑、挑战完成判定修复。
- **P1（已完成）**：装备部位/词条/套装、英雄主动技能 + 死灵法师、黄金按钮扩展、限时活动、日常任务、挑战扩容，并引入**内容模组化架构**（见下文）以避免 `game_data.json` 膨胀。
- **P2（已完成）**：批量购买（×1/×10/×100/Max 闭式结算）、统计页面、键盘快捷键（空格点击 / 1–5 技能）、音效开关、存档导出导入（base64）、转生预览对话框。
- **P3（部分完成）**：`fmt_num` 无穷大保护、cursor 被动产出修复、超大数字「尾数+指数」科学记法、转生公式超大数值稳定性、数值平衡校准（不变量测试）已完成；CI（GitHub Actions）仍延后。

## 快速开始

```bash
python main.py
```

零外部依赖，纯 Python 标准库。存档自动保存在 `idle_save.json`。

## 游戏系统

### 1. 纪元系统（阶段性目标）
- **6 个纪元**：石器 → 青铜 → 铁器 → 工业 → 数字 → 太空
- 累计收益达标后自动进阶，解锁新装备和技能
- 每个纪元提供全局 DPS 和点击力加成
- 顶部进度条实时显示当前纪元与下一纪元距离

### 2. 装备分类标签
- 5 种分类：**点击 / 产出 / 乘数 / 协同 / 功能**
- 商店按钮左侧色条标识分类，可点击顶部标签筛选
- 分类颜色：红（点击）蓝（产出）橙（乘数）紫（协同）绿（功能）

### 3. 英雄系统（巴尔的遗产灵感）
- **5 位英雄**：🧙 法师、🛡️ 圣骑士、🏹 游侠、⚔️ 狂战士、💀 死灵法师（P1 新增）
- 招募英雄花费金币，升级提升被动能力
- **被动加成**：
  - 法师：DPS +10%/级 | 圣骑士：点击力 +20%/级
  - 游侠：DPS +25%/级 + 暴击 10% | 狂战士：DPS +15%/级 + 点击力 +30%/级
  - 死灵法师（P1）：DPS +20%/级，外加主动召唤亡灵军团
- 英雄可装备掉落物品，获得额外属性加成（见 §4）

### 4. 装备掉落与词条系统（P1 重构）
- 5 种稀有度：**普通 / 魔法 / 传说 / 神话 / 不朽**（稀有度越高掉率越低，名词按稀有度着色）
- **4 个部位（插槽）**：⚔️ 武器、🛡️ 护甲、⛑️ 头盔、💍 饰品，每英雄独立穿戴
- **6 类随机词条**（按权重随机）：锋锐(dps)、精准(click)、致命(暴击)、贪婪(金币)、猎手(掉率)、全能(全属性)
  - 词条数值随稀有度放大：`普通 1.0 / 魔法 1.4 / 传说 2.2 / 神话 3.5 / 不朽 6.0`
  - 词条条数随稀有度：普通/魔法 1 条，传说/神话 2 条，不朽 3 条
- **3 套套装**（40% 概率掉落带套装归属的装备，按套件数结算加成，每套只计一次）：
  - 🐉 龙裔套装：2 件 DPS +25%、4 件 全属性 +20%
  - ✨ 圣光套装：2 件 点击力 +30%、4 件 金币 +50%
  - 🕳️ 虚空套装：2 件 暴击 +5%、4 件 掉率 +60%
- 在转生菜单 → 装备英雄界面中给英雄穿戴；装备栏显示部位图标与词条条数

### 5. 英雄主动技能（P1 新增）
除被动外，每位英雄拥有 1 个可按冷却释放的主动技能（UI 英雄面板内按钮）：

| 英雄 | 技能 | 效果类型 | 数值 | 持续 | 冷却 |
|------|------|----------|------|------|------|
| 🧙 法师 | 奥术新星 | DPS ×2 | — | 8s | 90s |
| 🛡️ 圣骑士 | 圣盾庇佑 | 点击力 ×50 | — | 10s | 120s |
| 🏹 游侠 | 箭雨 | 即时 DPS | 25s 当量 | — | 100s |
| ⚔️ 狂战士 | 狂暴 | DPS ×3 | — | 10s | 120s |
| 💀 死灵法师 | 亡灵军团 | 召唤（附加 5×等级 的 DPS） | — | 15s | 150s |

效果类型支持 `dps_mult`（乘法乘区）、`click_mult`（点击乘区）、`instant_dps`（一次性结算）、`summon`（按等级附加加性 DPS）。

### 6. 主动技能（科技树 5 种）
- 5 种技能，随纪元解锁：
  - 💰 **金币雨**：立刻获得 30 秒 DPS（石器）
  - ⏰ **时间加速**：DPS x3 持续 10 秒（青铜）
  - ⚡ **暴击连击**：下 10 次点击 x50（铁器）
  - 🤖 **自动连点**：每秒 5 次点击持续 15 秒（工业）
  - 🌟 **黄金风暴**：点击力 x1024 + DPS x5 持续 12 秒（数字）
- 各有独立冷却时间，声望升级可缩减冷却

### 7. 科技树（前置条件）
- 部分装备需要先购买其他装备达到指定等级
- 例如：click_booster 需要 clicker Lv.3，orcish_pride 需要 goblin Lv.1
- 不满足条件的装备显示锁定状态和纪元标签

### 8. 转生与挑战（P1 扩容）
- **转生**：重置进度，获得声望点数（公式：∛总收益）；新字段（日常/活动/英雄技能）在转生时正确保留/重置
- **声望商店**：用声望购买永久加成：DPS 提升、点击力提升、起始金币、冷却缩减
- **6 种挑战模式**（基础 3 + P1 新增 3）：
  - ☮ 和平主义 — 禁手动点击（x1.5 声望）
  - ⏱ 极速挑战 — 30 分钟达到青铜时代（x2.0 声望）
  - ✋ 纯手工 — 禁用 DPS 装备（x2.5 声望）
  - ♾ 无尽轮回（P1）— DPS 全局 ×0.5，需抵达数字时代（x3.0 声望）
  - 🚫 禁金试炼（P1）— 禁用黄金按钮（x1.8 声望）
  - ⚡ 闪电战（P1）— 10 分钟内抵达铁器时代（x2.2 声望）

### 9. 黄金按钮扩展（P1 新增）
- 闲置时随机弹出黄金按钮，P1 由单一类型扩展为 **5 种增益变体**（按权重随机，幸运型受「黄金幸运」升级加成）：
  - 🔥 黄金狂热：点击力 ×1024（16s）
  - 🌊 黄金溢流：DPS ×5（12s）
  - 💰 黄金掠夺：金币收益 ×3（20s）
  - 🌟 黄金丰收：掉率 ×8（30s）
  - 🍀 黄金幸运：立刻获得大额金币（即时）
- **4 项黄金升级**（商店·黄金类目，每项 5 级）：黄金延时（时长 +20%/级）、黄金强化（强度 +25%/级）、黄金频现（缩短刷新间隔）、黄金幸运（提高幸运/即时黄金概率）

### 10. 限时活动（P1 新增）
- 按调度轮换自动触发，提供全局乘区；顶部横幅提示当前活动与剩余时间
- **5 种活动**：🎉 黄金狂欢（黄金频率 ×2）、🎁 掉宝节（掉率 ×3）、⚡ 双倍产出（DPS ×2）、💰 财神日（金币 ×2）、🔥 狂热时刻（点击力 ×3）
- 活动调度受黄金频率类效果影响（如黄金狂欢会进一步缩短黄金按钮间隔）

### 11. 日常任务（P1 新增）
- 以本地日期驱动的每日刷新（独立于每日登录连击奖励）；跨日自动重置进度
- **6 个任务**（完成领取金币 / 声望奖励）：
  - 点击达人：今日点击 200 次 → 5000 金币
  - 采购狂：今日购买 10 次升级 → 20000 金币
  - 纪元探索：今日抵达青铜时代 → 50000 金币
  - 试炼者：今日完成 1 次挑战 → 1 声望
  - 武装起来：累计装备 4 件装备 → 30000 金币
  - 英雄成长：任一英雄达到 10 级 → 1 声望
- 右下角 📋 按钮查看与领取

### 12. 离线收益（P0 新增）
- 退出时记录墙上时钟时间戳，重新打开按当前 DPS 快进结算
- 离线收益上限可配置（`constants.offline_cap_seconds`，默认 8 小时）
- 打开游戏弹出"欢迎回来"结算提示

### 13. 自动保存（P0 新增）
- 每 30 秒自动保存一次（`constants.autosave_seconds`），关闭窗口时强制保存
- 防止崩溃/强杀导致整场进度丢失

### 14. 成就系统（P0 新增，P1 +4）
- 共 **34 个成就**（基础 30 + P1 新增 4：英雄满 5 位、完成 5 次挑战、转生 10 次、购买 500 次升级）
- 覆盖点击/金币/掉装/纪元/英雄/转生/挑战/升级；解锁后提供永久加成（全局 DPS 或点击力 +1%~10%）
- 成就进度跨转生永久保留；右下角 🏆 按钮查看面板，解锁时弹出提示

### 15. 每日奖励（P0 新增）
- 本地日期驱动的登录连击，连续领取天数越高奖励越多（第 7 天额外 +1 声望）
- 断签自动重置；右下角 📅 按钮领取

### 16. 里程碑系统（P0 新增）
- 同一产出装备拥有达到 25/50/100/200 件时，该装备产出分别 ×1.5/×2/×3/×5
- 商店按钮显示 `🎯 数量/下一里程碑`

> **已修复**：pacifist / no_dps 两类挑战此前因缺少 `time_limit` 而永远无法判定完成，其 1.5x/2.5x 声望倍率永不生效；现已在进入青铜时代时正确判定完成。

### 乘数联动（核心经济）
- **乘数联动**：noob_training → noob_clicker（2^n）
- **协同效应**：orcish_pride 激活 goblin × gremlin
- **力量联动**：noob_gremlin → gremlin → noob_clicker
- **全局乘数**：cps_multiplier（1.01^n）、click_booster（2^n）
- **统一金币结算**：所有金币产出（点击/挂机/技能）经 `_add_gold()` 统一叠加 词条金币 × 黄金金币 × 活动金币 三个乘区

## P2 / P3 路线图

### P2 体验改进（已完成）

- **批量购买**：顶栏 `×1 / ×10 / ×100 / Max` 切换；价格按等比闭式公式精确结算（几何级数成本 = `base·(rⁿ−1)/(r−1)`，固定表按逐项求和），Max 模式自动求解可购上限并回退到手头金币允许的最后一档。
- **统计页面**：📊 按钮打开统计窗，展示总点击、总收益、转生次数、挑战次数，以及**各纪元首次到达时间**。
- **键盘快捷键**：`空格` = 手动点击；数字 `1–5` = 释放对应主动技能（与科技树 5 技能对齐），任何对话框打开时自动禁用以免误触。
- **音效**：🔊 按钮开关提示音（点击 / 购买 / 技能 / 转生，基于 `winsound`，默认关闭；开关状态不持久化）。
- **存档导出 / 导入**：💾 按钮生成 base64 存档串（可复制备份），粘贴回导入即重建完整引擎状态（重跑初始化、纪元、英雄、活动与重算）。
- **转生预览**：转生确认窗展示「当前声望 / 将获得 / 转生后合计」以及声望商店可购项（按是否买得起标注 ✔/✖）。

### P3 修复与重构（已完成 / 部分）

- ✅ **`fmt_num` 无穷大保护**：`10**400` 等超界浮点不再抛 `OverflowError`，返回 `∞`（仅对 `float` 生效，整数分支走递归格式化）。
- ✅ **cursor（光标）被动产出修复**：cursor 升级现在按 `click_power × 等级 × dt` 正确产生被动金币（此前仅手动点击生效）。
- ✅ **超大数字科学记法（尾数 + 指数）**：超过 `10¹⁵` 统一显示为 `1.23e45` 形式（2 位小数尾数 + 整数指数，**无 `+` 号**），覆盖任意大整数（含 `10⁴⁰⁰` 等超浮点上限值）；小数字仍用千分位。避免超长整数字符串与浮点溢出。
- ✅ **转生公式数值稳定性**：`get_prestige_formula()` 改用**整数立方根（牛顿迭代）**，在 `total_gold > 10³⁰⁸`（浮点上限）乃至 `inf/nan` 时不再 `int(inf)` 崩溃，安全返回合理声望。
- ✅ **数值平衡校准（不变量测试）**：新增 `tests/test_balance.py`（22 用例），把健康数值结构编码为断言——纪元阈值严格递增、升级成本随等级非递减且为正、英雄/声望/技能/活动/黄金/挑战/装备/成就参数合法——使后续数据改动无法悄悄破坏平衡；并覆盖转生公式在超大/溢出数值下的安全性。
- ⏳ **CI（GitHub Actions）**：尚未接入自动测试流水线（可选，待定）。

> 平衡校准采用「锁定不变量 + 修复真实数值隐患」的工程化路线：实测数据未发现成本倒挂/阈值倒挂/奖励非正等问题，故未做主观调参；唯一真实缺陷是后期转生公式在超大数值下会崩溃，已修复。如希望针对具体玩法手感（如前期节奏、声望曲线）做调参，请提供目标数值。

## 内容模组化架构（P1 新增 · Cordis / 模组管理思路）

为避免 `game_data.json` 随 P1 大幅膨胀、并保持「核心包不可变、扩展包可插拔」，P1 引入类 Cordis/模组管理的**内容注册表**模式：

- **核心包**：`data/game_data.json`（英雄、挑战、技能等基础数组）+ `data/achievements.json` 保持不变。
- **模组包**：每个 P1 子系统一个独立文件 `data/modules/NN_p1_*.json`，通过两种合并方式挂接：
  - `extend`：向既有**数组型**内容（upgrades / skills / heroes / challenges / prestige_upgrades / achievements）追加条目，并做**跨包重复 key 校验**（重复 key 自动跳过并告警）。
  - `add`：新增**顶层内容键**（如 equipment_slots / equipment_affixes / equipment_sets / golden_variants / events / daily_tasks），并做**碰撞校验**（与核心或其他模组键冲突则跳过并告警）。
- **加载器**：`content_loader.py`（位于仓库根，刻意避开 `engine` 包以避免循环导入）在启动时按文件名顺序合并，`config.py` 再从中导出所有常量。
- **校验产物**：`CONTENT_ISSUES` 收集所有重复/碰撞告警（非致命），便于排查模组冲突。

| 模组文件 | 贡献内容 |
|----------|----------|
| `01_p1_equipment.json` | 装备部位 / 词条 / 套装 / 稀有度系数 |
| `02_p1_heroes.json` | 死灵法师（第 5 英雄）+ 主动技能 |
| `03_p1_golden.json` | 4 项黄金升级 + 5 种黄金变体 |
| `04_p1_events.json` | 5 种限时活动 |
| `05_p1_dailytasks.json` | 6 个日常任务 |
| `06_p1_challenges.json` | 3 个新挑战 |
| `07_p1_achievements.json` | 4 个新成就 |

> 新增玩法只需再放一个 `data/modules/NN_*.json`，无需改动核心数据与引擎装配逻辑。

```
│   ├── _golden.py          # 黄金按钮调度与增益

│   ├── _achievements.py / _daily.py / _era.py / _skills.py / _persistence.py
│   └── fmt.py / types.py / upgrade.py
├── ui.py                   # 渲染层（纪元条/标签/技能栏/商店/英雄面板/活动横幅）
├── data/
│   ├── game_data.json      # 核心游戏数据（core module，不可变）
│   ├── achievements.json   # 基础成就（core module）
│   └── modules/            # P1 内容模组包（可插拔）
├── tests/                  # 99 个测试（test_p0 / test_p1 / test_p2 / test_state / ...）
├── run_all_tests.py        # 离线测试入口（无 pytest/网络时可用）
├── fonts.py                # 本地中文字体加载
├── README.md
└── requirements.txt
```

### 架构

```
main.py  (组合根)
  ├── engine/  (纯逻辑层，mixin 组合)
  │     ├── GameState   — 可序列化状态（含声望/挑战/日常/活动，向下兼容旧存档）
```

## 技术要点

- **零外部依赖**：tkinter + json + dataclasses（测试用标准库 unittest 思路，`run_all_tests.py` 为离线桩入口）
- **数据驱动 + 模组化**：核心数据在 `game_data.json`，扩展内容以可插拔模组包挂接，运行时由 `content_loader.py` 合并并做重复/碰撞校验
- **存档兼容**：加载旧存档自动补齐新字段；装备 `equipped` 由单件迁移为 `{slot: item}` 部位字典
- **超大数字**：内置格式化器支持超过 10^308 的数字
- **统一经济**：金币产出经 `_add_gold()` 集中结算，乘区可叠加（词条 / 黄金 / 活动）
