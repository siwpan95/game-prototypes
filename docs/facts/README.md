# 事实源类 · 准入与现状

## 什么算一条事实源

**当前状态的权威台账**：别的文档与脚本从这里读值，而不是各自记一份。

判据：如果一个值会被多处引用、且**过期后会导致错误结论**，它就该是事实源。
例如：本机工具链版本与判据、门禁基线状态、外部依赖的钉死版本。

每条事实源必须带三样东西，缺一不可：

1. **时点** —— 这条事实是什么时候观测的；
2. **观测命令** —— 别人怎么自己复核（要能直接粘贴执行）；
3. **过期条件** —— 什么情况下这条事实不再成立。

## 为什么现在是空的

本仓当前没有任何「被多处引用的状态值」：
- 测试与冒烟结果写在 `README.md` 的「测试状态」，只此一处引用；
- 外部依赖版本钉在 `package.json` / `pyproject.toml` 里，那才是它们的唯一真相源；
- 治理规则的判据在分发版治理落地（DSH 检出内的 `governance/`），本仓不复制一份。

**等出现第二处引用同一状态值的时候，再建这条事实源**——提前建台账只会多一份会过期的东西。
