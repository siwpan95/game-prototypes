# Progress Quest Multiverse - 主题开发指南

## 概述

主题系统采用 **文件夹 + 多 JSON 文件 + Python 加载器** 的架构，类似 mod 管理器：

- **加载器**（`theme_loader.py`）自动扫描 `themes/data/` 目录下的**子文件夹**
- 每个子文件夹是一个完整主题，包含 **8 个固定名称的 JSON 文件**
- 所有主题文件夹的文件名和数量完全一致，只有内容不同
- **新增主题**只需复制一个现有主题文件夹，修改内容即可，无需改任何 Python 代码
- **基类**（`theme_base.py`）提供通用逻辑（随机怪物、随机任务等），不依赖具体数据

## 8 个标准 JSON 文件

每个主题文件夹必须包含以下 8 个文件，**名称和数量统一**：

| 文件名 | 内容 | JSON 类型 |
|--------|------|-----------|
| `meta.json` | 主题元数据（id、名称、描述、UI 标签） | 对象 |
| `races.json` | 可选种族列表 | 字符串数组 |
| `classes.json` | 可选职业列表 | 字符串数组 |
| `spells.json` | 法术池（升级时随机学习） | 字符串数组 |
| `tasks.json` | 活跃任务目标池 | 二元数组 `[[动词, 名词], ...]` |
| `monsters.json` | 怪物定义（含掉落表） | 对象数组 |
| `equipment.json` | 商店装备列表 | 对象数组 |
| `quests.json` | 任务模板 | 对象数组 |

## 如何创建新主题

### 第一步：复制文件夹

复制一个现有主题文件夹（如 `data/warcraft/`），重命名为你的主题名：

```bash
cd src/themes/data
cp -r warcraft my_theme
```

### 第二步：修改 8 个 JSON 文件的内容

逐个修改每个 JSON 文件的内容，文件名保持不变。

#### meta.json — 主题元数据

```json
{
  "id": "my_theme",
  "name": "我的主题",
  "description": "一段描述文案",
  "race_label": "种族",
  "class_label": "职业",
  "monster_label": "怪物"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | str | 是 | 主题唯一标识，用于引擎引用和存档文件名 |
| `name` | str | 是 | 显示名称（开始界面、日志中展示） |
| `description` | str | 是 | 描述文案 |
| `race_label` | str | 否 | 种族的 UI 标签（默认"种族"，原神用"地区"） |
| `class_label` | str | 否 | 职业的 UI 标签（默认"职业"，原神用"武器类型"） |
| `monster_label` | str | 否 | 怪物的 UI 标签（默认"怪物"，宝可梦用"宝可梦"） |

#### races.json — 种族列表

```json
["人类", "矮人", "暗夜精灵", "兽人", "亡灵"]
```

#### classes.json — 职业列表

```json
["战士", "法师", "猎人", "牧师", "术士"]
```

#### spells.json — 法术池

```json
["闪电箭", "冰霜震击", "火球术", "治疗术", "暴风雪"]
```

#### tasks.json — 任务目标池

二元数组，每个元素是 `[动词, 名词]`：

```json
[
  ["获取", "一篮苹果"],
  ["消灭", "一些哥布林"],
  ["寻找", "一些宝石"],
  ["交付", "一封信件"]
]
```

#### monsters.json — 怪物定义

```json
[
  {
    "name": "森林灰狼",
    "level": 1,
    "hp": 30,
    "exp_reward": 50,
    "loot_table": [
      {"item": {"name": "狼皮", "value": 5, "item_type": "misc"}, "drop_chance": 0.8},
      {"item": {"name": "狼肉", "value": 3, "item_type": "misc"}, "drop_chance": 0.9}
    ]
  }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | str | 怪物名称（任务目标通过此名称匹配） |
| `level` | int | 等级（引擎按 `角色等级+2` 筛选可用怪物） |
| `hp` | int | 生命值 |
| `exp_reward` | int | 经验奖励（参考值，实际经验随时间获得） |
| `loot_table` | array | 掉落表，每项为 `{"item": {...}, "drop_chance": 0.0-1.0}` |

#### equipment.json — 商店装备

```json
[
  {"name": "铁匠锤", "value": 100, "item_type": "weapon", "stat_bonus": {"strength": 3}},
  {"name": "皮甲外套", "value": 150, "item_type": "armor", "stat_bonus": {"constitution": 2}}
]
```

物品字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | str | 物品名称 |
| `value` | int | 价值/售价 |
| `item_type` | str | 类型：`weapon`/`armor`/`helmet`/`boots`/`shoulder`/`gloves`/`misc` |
| `stat_bonus` | object | 属性加成，如 `{"strength": 3, "dexterity": 1}` |
| `count` | int | 堆叠数（默认 1） |
| `level` | int | 物品等级（默认 1） |

#### quests.json — 任务模板

```json
[
  {
    "name": "消灭石腭怪",
    "description": "在艾尔文森林消灭石腭怪",
    "target_monster": "石腭怪",
    "target_count": 10,
    "reward_exp": 200,
    "reward_gold": 50,
    "reward_item": {"name": "石腭怪护符", "value": 50, "item_type": "misc", "stat_bonus": {"constitution": 1}}
  }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | str | 任务名称（运行时自动追加随机编号） |
| `description` | str | 任务描述 |
| `target_monster` | str | 目标怪物名称（**必须**在 monsters.json 中存在） |
| `target_count` | int | 目标数量（运行时随机 3-8） |
| `reward_exp` | int | 经验奖励 |
| `reward_gold` | int | 金币奖励 |
| `reward_item` | object/null | 奖励物品（可选，结构同物品） |

| 键 | 中文 | 说明 |
|----|------|------|
| `strength` | 力量 | 影响攻击力和负重上限 |

## 注意事项

1. **文件夹名** 建议与 `meta.json` 中的 `id` 一致，但不强制。
2. **8 个文件缺一不可**，缺少任何文件会导致加载失败。
3. **物品类型** 必须为 `weapon`/`armor`/`helmet`/`boots`/`shoulder`/`gloves`/`misc` 之一。
4. **怪物等级** 建议覆盖 1-15 级，确保角色成长过程中始终有合适的怪物。
5. **掉落概率** 建议 0.05-0.9，太低会导致玩家很难获得物品。
6. **任务目标怪物** 必须在 `monsters.json` 中存在，否则任务无法完成。
7. **meta.id** 必须唯一。
8. **JSON 编码** 必须使用 UTF-8，确保中文字符正常显示。
