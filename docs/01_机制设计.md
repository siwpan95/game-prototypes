第一部分：机制 Overhaul 版（The Mechanics）

设计哲学：“硬核模拟 + 叙事驱动”  

机制不再只是数值增减，而是对角色状态的物理/精神模拟。每一次掷骰都是命运的审判。

1. 核心属性系统（The Stats）

1.1 六维属性重定义

属性 英文名 机制含义 临界阈值效果

力量 Strength 物理干涉能力，决定能否打破环境 ≥15：战神（无视常规战斗失败）<br>≤2：病弱

智慧 Wisdom 洞察与规避能力，决定能否看破陷阱 ≥15：先知（预知下一事件类型）<br>≤2：愚钝

荣耀 Glory 社会声望与英雄宿命，结局门票 ≥20：封神<br>≤0：无名之辈（无法触发荣耀结局）

神恩 DivineFavor 神明支持度，用于抵消疯狂与灾厄 ≤0：被遗弃（遗物失效）<br>≥15：半神容器

疯狂 Madness 理性侵蚀，高风险高回报 ≥10：幻觉（看到虚假选项）<br>≥20：湮灭（强制结局）

生命 Vitality 肉体存续，不仅是HP，更是意志 ≤0：死亡

1.2 属性软上限与衰减

为了防止无脑堆叠，引入边际效应递减：
def get_effective_stat(base_stat):
    if base_stat <= 10:
        return base_stat
    # 超过10点后，每点收益减半
    return 10 + (base_stat - 10) * 0.5


2. 动态难度与检定公式（The Math）

2.1 章节缩放曲线

难度不再是固定值，而是随章节指数级上升。

章节 基础需求 波动区间 失败惩罚倍率

1-3 5-6 ±1 1.0x

4-6 7-8 ±2 1.2x

7-9 9-10 ±3 1.5x

10-12 12-14 ±4 2.0x

2.2 检定算法（D20 变体）

采用类似 D&D 的直观检定，增加“大成功/大失败”戏剧性：
def roll_check(stat_value, difficulty):
    roll = random.randint(1, 20)
    total = roll + stat_value
    
    if roll == 20: return "CRIT_SUCCESS"  # 无视条件达成
    if roll == 1:  return "CRIT_FAILURE"  # 灾难性后果
    
    if total >= difficulty: return "SUCCESS"
    return "FAILURE"


3. 全局世界状态（The World State）

这是游戏的记忆中枢。不再只看属性，而是看“你做过什么”。

3.1 状态存储结构

world_state = {
    "flags": {

    "counters": {
        "times_refused_help": 3,

3.2 条件触发器（Trigger）

事件不再仅由属性触发，而是由行为触发：
"conditions": {
  "logic": "AND",
  "rules": [
    { "type": "stat", "name": "荣耀", "op": ">=", "value": 10 },
    { "type": "flag", "name": "betrayed_athena", "value": false },
    { "type": "counter", "name": "times_refused_help", "op": "<", "value": 2 }
  ]
}


4. 章节调度与肉鸽混合（The Loop）

4.1 章节主树（Mandatory）

• 强制执行 entry_event。

• 剧情不可逆，决定该章节的基调（如：暴力流 vs 智取流）。

4.2 章节间乱入（Roguelite）

• 在主树节点结束后，70% 概率进入下一节点，30% 概率触发 Interlude（随机事件）。

• 疲惫机制：连续战斗章节后，休息事件权重翻倍。

4.3 章节专属机制（Chapter Mechanics）

每个章节引入临时规则，打破单调：

章节 机制名称 效果描述

第2章 九头蛇 再生 力量判定失败不扣血，改为扣最大生命上限。

第5章 牛棚 污秽 每回合自动扣 1 点神恩，除非选择亵渎选项。

第11章 金苹果 时间诅咒 每做出一个选择，疯狂+1，必须在限定回合内通关。

5. 遗物与钩子系统（The Relics）

遗物不再是被动数值，而是改变规则的插件。

5.1 钩子类型

RELIIC_HOOKS = {
    "ON_TURN_START": "每回合开始时触发",
    "ON_STAT_CHECK_BEFORE": "检定前修正骰子",
    "ON_DEATH": "死亡时替代判定",
    "ON_CHAPTER_ENTER": "进入章节时强制修改属性"
}


5.2 示例：涅墨亚狮皮（进阶版）

{
  "id": "lion_cape",
  "hooks": {
    "ON_STAT_CHECK_BEFORE": "if context.stat == '力量': context.bonus += 2",
    "ON_DEATH": "if world_state.chapter_id == 'chapter_01': prevent_death(); set_stat('疯狂', 5);"
  }
}


6. 结局与评分系统（The End）

6.1 路径结局矩阵

结局由最终属性 + 关键路径选择共同决定。

结局类型 属性要求 路径要求（示例）

7. 多周目与解锁（Meta Progression）

7.1 解锁代币

通关后获得的不是数值，而是权限：
• “神之视角”：解锁查看敌人抗性。

• “命运织线”：开局携带一件普通遗物。

• “新角色池”：解锁奎托斯（疯狂流）、贝奥武夫（荣耀流）。

7.2 章节选择模式

通关一次后，主菜单解锁“挑战模式”：
• 允许直接从第7章开始。

• 限制属性上限（如：力量封顶10）。

• 禁用遗物槽位。

✅ 机制部分总结

这套机制确保了：
1. 深度：数值与剧情深度绑定。
2. 重玩性：不同的属性加点对应完全不同的事件解法。
3. 叙事感：机制本身就是故事（如疯狂值导致幻觉选项）。
