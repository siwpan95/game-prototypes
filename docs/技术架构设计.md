# 技术架构设计文档

## 1. 技术栈详细规划

### 1.1 编程语言和框架
- **主编程语言**：Python 3.11+
  - 理由：用户熟悉，开发效率高，丰富的第三方库
- **GUI框架**：Tkinter（标准库）或 CustomTkinter（现代化UI）
  - Tkinter：轻量，无需额外安装，适合简单UI
  - CustomTkinter：现代化UI，外观更接近原生应用
- **游戏逻辑**：纯Python
- **数据存储**：
  - JSON：适合配置文件、游戏数据
  - SQLite：适合存储角色进度、统计等结构化数据
- **多媒体**：pygame-ce（用户熟悉）
  - 用于音效播放和简单动画

### 1.2 开发工具
- **IDE**：VS Code或PyCharm
- **版本控制**：Git
- **打包工具**：PyInstaller
- **测试框架**：pytest
- **文档生成**：Markdown + MkDocs（可选）

```python
        self.current_value = 0

        self.current_value = value

        self.progress_bar.config(value=value)
```

```python
import json

class GameData:
    def __init__(self, theme="wow"):
        self.theme = theme
        self.races = []
        self.classes = []
        self.items = []
        self.quests = []
        self.enemies = []
        self.load_data()
    
    def load_data(self):
        """加载游戏数据"""
        # 从JSON文件加载数据
        with open(f"data/{self.theme}/races.json", "r", encoding="utf-8") as f:
            self.races = json.load(f)
        
        with open(f"data/{self.theme}/classes.json", "r", encoding="utf-8") as f:
            self.classes = json.load(f)
        
        with open(f"data/{self.theme}/items.json", "r", encoding="utf-8") as f:
            self.items = json.load(f)
        
        with open(f"data/{self.theme}/quests.json", "r", encoding="utf-8") as f:
            self.quests = json.load(f)
        
        with open(f"data/{self.theme}/enemies.json", "r", encoding="utf-8") as f:
            self.enemies = json.load(f)
    
    def get_race(self, race_id):
        """获取种族数据"""
        for race in self.races:
            if race["id"] == race_id:
                return race
        return None
    
    def get_class(self, class_id):
        """获取职业数据"""
        for class_ in self.classes:
            if class_["id"] == class_id:
                return class_
        return None
    
    def get_item(self, item_id):
        """获取物品数据"""
        for item in self.items:
            if item["id"] == item_id:
                return item
        return None
```

### 2.4 游戏模块（games）

#### wow_module.py - 魔兽世界主题模块
```python
from data.wow_data import WOW_RACES, WOW_CLASSES, WOW_ITEMS, WOW_QUESTS, WOW_ENEMIES
from core.character import Character
from core.quest import Quest, QuestGenerator
from core.combat import Combat
from core.equipment import Item, EquipmentManager

class WoWModule:
    def __init__(self):
        self.name = "World of Warcraft"
        self.races = WOW_RACES
        self.classes = WOW_CLASSES
        self.items = WOW_ITEMS
        self.quests = WOW_QUESTS
        self.enemies = WOW_ENEMIES
    
    def create_character(self, name, race_id, class_id):
        """创建魔兽世界主题角色"""
        race = next((r for r in self.races if r["id"] == race_id), None)
        class_ = next((c for c in self.classes if c["id"] == class_id), None)
        
        if not race or not class_:
            return None
        
        # 计算初始属性
        stats = {
            "STR": 3 + race["stats"].get("STR", 0) + class_["stats"].get("STR", 0),
            "CON": 3 + race["stats"].get("CON", 0) + class_["stats"].get("CON", 0),
            "DEX": 3 + race["stats"].get("DEX", 0) + class_["stats"].get("DEX", 0),
            "INT": 3 + race["stats"].get("INT", 0) + class_["stats"].get("INT", 0),
            "WIS": 3 + race["stats"].get("WIS", 0) + class_["stats"].get("WIS", 0),
            "CHA": 3 + race["stats"].get("CHA", 0) + class_["stats"].get("CHA", 0)
        }
        
        return Character(name, race["name"], class_["name"], stats)
    
    def generate_quest(self, character_level):
        """生成魔兽世界主题任务"""
        # 根据角色等级筛选可用任务
        available_quests = [q for q in self.quests if q.get("min_level", 1) <= character_level <= q.get("max_level", 99)]
        
        if not available_quests:
            return None
        
        # 随机选择一个任务
        import random
        quest_data = random.choice(available_quests)
        
        return Quest(
            quest_data["name"],
            quest_data["description"],
            quest_data["objectives"],
            quest_data["rewards"]
        )
    
    def generate_enemy(self, character_level):
        """生成魔兽世界主题敌人"""
        # 根据角色等级筛选可用敌人
        available_enemies = [e for e in self.enemies if abs(e["level"] - character_level) <= 3]
        
        if not available_enemies:
            return None
        
        # 随机选择一个敌人
        import random
        enemy_data = random.choice(available_enemies)
        
        return Character(enemy_data["name"], "Enemy", "Enemy", enemy_data["stats"])
```

### 3.2 游戏主循环
```python
def main_loop(character, theme_module):
    """游戏主循环"""
    import time
    
    while True:
        # 生成任务
        quest = theme_module.generate_quest(character.level)
        
        # 模拟任务进行
        while quest.progress < 100:
            # 更新任务进度
            quest.update_progress(1)
            
            # 随机遭遇敌人
            if random.random() < 0.3:  # 30%几率遭遇敌人
                enemy = theme_module.generate_enemy(character.level)
                combat = Combat(character, enemy)
                combat_log = combat.simulate_combat()
                # 显示战斗日志
                print(combat_log)
            
            # 随机获得物品
            if random.random() < 0.2:  # 20%几率获得物品
                item = theme_module.generate_item(character.level)
                character.inventory.append(item)
                # 显示获得物品消息
                print(f"获得物品: {item.name}")
            
            # 更新角色经验值
            character.exp += 10
            
            # 检查是否升级
            if character.exp >= character.exp_to_next_level:
                character.level_up()
                # 显示升级消息
                print(f"升级! 当前等级: {character.level}")
            
            # 更新UI
            update_ui()
            
            # 等待一段时间
            time.sleep(1)  # 每秒更新一次
        
        # 完成任务
        quest.complete()
        # 显示完成任务消息
        print(f"完成任务: {quest.name}")
```

## 4. 性能优化考虑

### 4.1 数据加载优化
- 使用懒加载：只在需要时才加载数据
- 使用缓存：缓存常用数据，减少IO操作
- 使用二进制格式：考虑使用pickle或msgpack代替JSON

### 4.2 UI更新优化
- 使用双缓冲：减少界面闪烁
- 限制更新频率：每秒更新一次UI，而不是每次数据变化都更新
- 使用异步更新：使用多线程或异步IO更新UI

### 4.3 内存占用优化
- 及时释放不需要的对象
- 使用对象池：重用常用对象
- 使用生成器：处理大量数据时使用生成器
