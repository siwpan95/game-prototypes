# 开发指南

## 1. 环境设置

### 1.1 安装Python
- 下载并安装Python 3.11+：https://www.python.org/downloads/
- 确保将Python添加到PATH环境变量

### 1.2 安装依赖库
```bash
# 创建虚拟环境（可选但推荐）
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 安装依赖库
pip install customtkinter  # 现代化Tkinter
pip install pygame-ce     # 多媒体支持
pip install pytest         # 测试框架
```

### 1.3 克隆或下载项目
```bash
# 如果使用Git
git clone https://github.com/yourusername/pq_multiverse.git
cd pq_multiverse

# 或者手动下载项目文件
```

## 3. 开发流程

### 3.1 核心模块开发

#### 步骤1：实现角色系统
1. 创建`src/core/character.py`
2. 实现`Character`类
3. 实现角色创建、升级、装备等功能
4. 编写测试用例

#### 步骤2：实现任务系统
1. 创建`src/core/quest.py`
2. 实现`Quest`和`QuestGenerator`类
3. 实现任务生成、更新、完成等功能
4. 编写测试用例

#### 步骤3：实现战斗系统
1. 创建`src/core/combat.py`
2. 实现`Combat`类
3. 实现战斗模拟、伤害计算、日志生成等功能
4. 编写测试用例

#### 步骤4：实现装备系统
1. 创建`src/core/equipment.py`
2. 实现`Item`和`EquipmentManager`类
3. 实现装备生成、装备、比较等功能
4. 编写测试用例

#### 步骤5：实现进度系统
1. 创建`src/core/progress.py`
2. 实现`ProgressTracker`类
3. 实现进度跟踪、统计等功能
4. 编写测试用例

### 3.2 UI模块开发

#### 步骤1：实现主窗口
1. 创建`src/ui/main_window.py`
2. 实现`MainWindow`类
3. 创建主窗口布局、菜单等
4. 集成各个面板

#### 步骤2：实现角色状态面板
1. 创建`src/ui/character_panel.py`
2. 实现`CharacterPanel`类
3. 显示角色属性、装备等信息
4. 实现更新功能

#### 步骤3：实现任务进度面板
1. 创建`src/ui/quest_panel.py`
2. 实现`QuestPanel`类
3. 显示任务名称、描述、进度等
4. 实现更新功能

#### 步骤4：实现战斗日志面板
1. 创建`src/ui/combat_log.py`
2. 实现`CombatLogPanel`类
3. 显示战斗日志
4. 实现自动滚动功能

#### 步骤5：实现进度条组件
1. 创建`src/ui/progress_bar.py`
2. 实现`ProgressBar`类
3. 显示各种进度条
4. 实现更新功能

### 3.3 数据模块开发

#### 步骤1：实现游戏数据管理
1. 创建`src/data/game_data.py`
2. 实现`GameData`类
3. 实现数据加载、查询等功能

#### 步骤2：实现魔兽世界主题数据
1. 创建`src/data/wow_data.py`
2. 定义魔兽世界主题的种族、职业、装备、任务、敌人等数据

#### 步骤3：实现原神主题数据

#### 步骤4：实现宝可梦主题数据

2. 定义宝可梦主题的种族、职业、装备、任务、敌人等数据

### 3.4 游戏模块开发

#### 步骤1：实现魔兽世界主题模块
1. 创建`src/games/wow_module.py`
2. 实现`WoWModule`类

#### 步骤2：实现原神主题模块

3. 实现角色创建、任务生成、敌人生成等功能

#### 步骤3：实现宝可梦主题模块
1. 创建`src/games/pokemon_module.py`
2. 实现`PokemonModule`类
3. 实现角色创建、任务生成、敌人生成等功能

### 3.5 主程序开发

#### 步骤1：创建主程序入口

## 6. 打包和发布

### 6.1 创建requirements.txt
```
customtkinter>=5.2.0
pygame-ce>=7.0.0
pytest>=7.0.0
```

### 6.2 使用PyInstaller打包
```bash
# 安装PyInstaller
pip install pyinstaller

# 打包成单个可执行文件
pyinstaller --onefile --windowed --name="Progress Quest Multiverse" src/main.py

# 打包结果在dist/目录下
```

### 6.3 创建安装程序
- 使用Inno Setup（Windows）
- 使用DMG Canvas（macOS）

## 7. 常见问题解决

### 7.1 依赖库安装问题
- 问题：pip安装失败
- 解决：使用国内镜像源
  ```bash
  pip install -i https://pypi.tuna.tsinghua.edu.cn/simple customtkinter
  ```

### 7.2 UI显示问题
- 问题：Tkinter界面显示不正常
- 解决：检查DPI缩放设置，使用CustomTkinter

### 7.3 性能问题
- 问题：游戏运行卡顿
- 解决：优化UI更新频率，使用异步更新
