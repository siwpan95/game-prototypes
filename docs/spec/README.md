## 效力等级

| 等级 | 含义 | 违反的后果 |
| --- | --- | --- |
| **铁律** | 最高效力，改动需要用户拍板 | 公开历史被污染、追不回来 |
| **规范** | 未来必须照着做 | 产生可识别的错误（结构债、找不到东西、行为漂移） |
| **事实源** | 当前状态的权威台账 | 过期结论被当作权威继续使用 |

本仓当前只有「规范」这一级（尚无铁律与事实源文档）。规范**不重编编号**：
新增用下一个号，废弃写状态而不是删号。

## 引用格式

`SPEC-101 §阶段 M2` 形式：编号 + 章节锚点。跨文档引用一律用这个形式，
让读者能一次定位；**只写「见某文档」不算引用**。

## 每条规范必须带的头部字段

编号 / 效力 / 状态 / 生效 / 最后修订 / 适用面 / 承载体 / 引用格式。
「承载体」回答一个问题：**这条规则被破坏时，什么会变红？**
没有机械承载体就如实写「无机械门禁」并说明由什么守着（例如测试或流程纪律），
不要暗示存在并不存在的覆盖。
