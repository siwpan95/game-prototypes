## 什么算一条记录

**只发生过一次、以后不会再发生的事**：一次事故、一次迁移、一次调研、一次改造的实测证据。

判据：如果它写的是「以后每次都该这么做」，那它是规范，该放 `spec/`；
如果它写的是「这一次我们观测到什么、做了什么决定」，那它是记录，放这里。

## 命名与纪律

- 文件名**必须带日期**（`主题_YYYY-MM-DD.md`），或者是一个**月份卷**（`主题-YYYY-MM/`，卷内自带 `README.md` 做入口）。
- **只追加，不修改结论**：后面发现前面的结论错了，新写一条记录并在其中说明修正了哪一条，不要就地改写历史。
- 记录**不作为当前要求被引用**；其中持久的部分要提炼进 `spec/`。
- 每条记录必须能让别人**复现证据**：写清执行了什么命令、看到什么输出。
