# Progress Quest Multiverse - 项目设计文档（更新版）

## 项目概述

**Progress Quest Multiverse** 是 [progressquest.com](https://progressquest.com/) 的复刻版，结合多个游戏世界内容，打造"多元宇宙"自动冒险体验。

**当前状态**：原型阶段 ✅  
**下一步**：原型确认后进入迭代开发

---

## 核心机制（已验证）

基于官网机制完善，完全复刻原版 Progress Quest：

```
击杀怪物 → 获得战利品 → 负重满回城 → 出售获得金币
→ 购买装备 → 完成任务 → 获得经验 → 升级
```

### 四个核心进度条
| 进度条 | 说明 | 增长方式 |
|--------|------|----------|
| **经验条 (ExpBar)** | 升级所需经验 | 击杀怪物获得经验 |
| **剧情条 (PlotBar)** | 剧情章节进度 | 剧情事件推进 |
| **任务条 (QuestBar)** | 当前任务进度 | 击杀指定怪物 |
| **负重条 (EncumBar)** | 背包负重百分比 | 拾取战利品 |

### 与原版 Progress Quest 的差异
- ✅ 完全复刻核心机制
- ✅ 需要程序运行才有进度（无离线收益）
- ✅ 自动存档（升级/完成任务/停止时）

## 主题系统（高度工具化 ✅）

### 设计目标
- **高度工具化**：每个主题只需填充数据，无需修改引擎
- **可重复性**：复制示例主题文件，替换数据即可创建新主题
- **便于后期增加内容**：新增主题不影响现有代码

### 主题文件结构
```
src/themes/
├── theme_base.py            # 主题基类（GameTheme）
├── warcraft_theme.py       # 魔兽世界（完整示例 ✅）
├── genshin_theme.py       # 原神（完整示例 ✅）
└── pokemon_theme.py      # 宝可梦（完整示例 ✅）
```

### 创建新主题的步骤
1. 复制 `warcraft_theme.py`
2. 重命名（如 `xxx_theme.py`）
3. 修改 `setup_data()` 中的数据
4. 在 `themed_engine.py` 中注册
5. 运行测试

详细指南见 `docs/主题开发指南.md`

## 已知问题和注意事项

### 问题 1：游戏节奏偏慢
- **现象**：升级需要 20 分钟（原版设定）
- **解决方案**：调整 `exp_to_next_level` 计算公式，或添加"加速"按钮

### 问题 2：怪物数据较少
- **现象**：目前每个主题只有 6 种怪物
- **解决方案**：迭代开发中增加更多怪物

### 问题 3：UI 不够美观
- **现象**：Tkinter 默认样式较简陋
- **解决方案**：阶段 3 中使用 CustomTkinter 或 pygame-ce 改进 UI
